Required System Configuration

Minimum viable specification for every environment. All values below are mandatory, not advisory.

1. Developer workstation

Operating systemmacOS 12+, Windows 10/11 with WSL2, or Ubuntu 22.04+
CPU2 cores
RAM8 GB
Free disk10 GB
Node.js18.x LTS
Package managerpnpm 8+
Go1.21+
Git2.40+
BrowserChromium, Chrome or Edge, current
NetworkOutbound HTTPS to source control and the PostgreSQL host
CredentialsNon-production DSN and non-production admin account

2. Application host (staging or production)

Operating systemUbuntu 22.04 LTS
CPU2 vCPU
RAM4 GB
Disk40 GB SSD
Persistent volumeDurable mount for backend/uploads/
Node.js18.x LTS
Go toolchain1.21+ (build only)
Process managerPM2, with pm2 startup and pm2 save
Reverse proxyNginx or Caddy terminating TLS
Frontend port3000 (peepal-frontend)
API port8080 (PORT; .env.example uses 3001 locally)
Public ports443 only; 80 redirecting to 443
DNSWildcard record for tenant subdomains, plus an API hostname
OutboundHTTPS to the database and the SMTP relay

3. Database

EnginePostgreSQL 14+
DriverGORM with pgx
Storage10 GB
TransportTLS enforced
Access controlIP allowlist or private networking
BackupsDaily automated snapshots
Schema changesOnly via main.go --migrate, run deliberately

4. Required environment variables

VariableRequirement
DB_PATHPostgreSQL DSN
PORTAPI listen port; falls back to 8080
COOKIE_DOMAINCookie scope. Must be empty on localhost
JWT / admin seed secretsUnique per environment
SMTP settingsRequired for invitations and notifications
NEXT_PUBLIC_API_URLOrigin of the Go API
NODE_ENV / PORTproduction / 3000 on the host
Never commit a real .env or .env.local. Inject secrets at the host or through a secret manager.

5. End-user device

BrowserChrome, Edge, Firefox or Safari, within the last two major versions
Screen1280 × 720
CookiesFirst-party cookies allowed for the Peepal domain
JavaScriptEnabled
NetworkStable broadband, no captive portal
Desktop required for dense admin tables and bulk CSV tools. Mobile browsers are supported for everyday modules only.

6. Non-negotiable operating rules

  • Sessions use the httpOnly cookie peepal_token, valid 24 hours. Cookies must not be stripped by the proxy.
  • The proxy must forward the tenant header and cookies unchanged.
  • backend/uploads/ must be included in the backup policy alongside the database.
  • Change the seeded administrator credentials before the instance is reachable by anyone else.
  • Login is blocked without an active subscription on the tenant.
